# 🔢 数学乐园 · Math Fun

一个给 5–7 岁孩子的数学游戏：跟着小狮子乐乐数数、比大小、认图形、学加减法。
课程顺序参照 **人教版（2024）小学数学一年级上册**，共 30 课。**中文和英文都可以玩**（开始页面或家长页面切换），手机、平板和电脑都能玩。

**▶ 开始玩：** https://lionnevergrowup.github.io/MathGame/

开始页面：https://lionnevergrowup.github.io/MathGame/#/start · 家长页面：https://lionnevergrowup.github.io/MathGame/#/parents ·
直接用英文打开：https://lionnevergrowup.github.io/MathGame/?lang=en

*A first-grade math game for young children, the companion of [中文乐园](https://lionnevergrowup.github.io/chineselearner/)
and [Phonics Fun](https://lionnevergrowup.github.io/95percentgroup/). It follows the first-semester math book used in
schools in China (人教版 2024, 30 lessons): counting, comparing, positions, sorting, number bonds, adding and taking
away, 3D shapes, numbers to 20 and making a ten. Leo the lion speaks every instruction, in Chinese or in English.*

## 课程

| 单元 | 课 | 内容 |
|---|---|---|
| 数学游戏 | 1–4 | 数一数 · 比一比 · 认位置 · 分一分 |
| 第一单元 5以内数的认识和加、减法 | 5–11 | 1～5的认识 · 比大小 · 第几 · 分与合 · 加法 · 减法 · 0的认识 |
| 第二单元 6～10的认识和加、减法 | 12–19 | 6和7 · 6和7的加减法 · 8和9 · 8和9的加减法 · 10的认识 · 10的加减法 · 连加连减 · 加减混合 |
| 第三单元 认识立体图形 | 20 | 长方体、正方体、圆柱、球 |
| 第四单元 11～20的认识 | 21–23 | 11～20的认识 · 数的顺序（计数器、十位个位）· 十加几和相应的减法 |
| 第五单元 20以内的进位加法 | 24–27 | 9加几 · 8、7、6加几 · 5、4、3、2加几 · 解决问题 |
| 第六单元 复习与关联 | 28–30 | 复习：数 · 复习：计算 · 复习：图形和位置 |

游戏里的题目、图画和小故事都是为这个游戏编写的，不是课本原文；数字儿歌（1像铅笔细长条……）是传统儿歌。

## 小游戏

每课有 2–4 个小游戏：

| 游戏 | 孩子做什么 |
|---|---|
| 🔢 数一数 | 先点数字卡（5 🍎🍎🍎🍎🍎 五），再数一数有几个、戳破对的气球；也会“找一找哪一组有 5 个”，或者在一堆东西里只数小鸟。点一点图里的东西，乐乐会一个一个地数 |
| 🧺 摆一摆 | 按数字把东西放到盘子里，多了点一下拿走；11～20 用“一捆十根”的小棒摆 |
| ✏️ 写数字 | 在日字格里从绿点开始、跟着箭头一笔一笔写 0～9（4 和 5 写两笔），写对了乐乐念数字儿歌；“看一看”会演示怎么写 |
| 🎨 画一画 | 画几样东西，数一数，再贴上数字标签，可以保存图片 |
| ⚖️ 比多少 · 📏 比长短 · 🏢 比高矮 | 一个对一个比多少；铅笔一头对齐比长短；楼站在同一条地面上比高矮 |
| ↕️ ↔️ 🏃 认位置 | 书架上的上下、桌子上的左右、赛跑的前后（离终点近的在前面）|
| 🗂️ 分一分 | 按种类、颜色、大小、形状把东西放进筐里，最后数一数一个筐里有几个 |
| 🐊 比大小 · 🪜 排一排 | 认识 >、<、=（开口朝着大数），比两个数，找最大最小，从小到大排数 |
| 🥇 第几 | 从左边（或右边）数，第几个是谁、谁排第几；分清“三只”和“第三只” |
| 🍑 分与合 · 🃏 凑数 | 5 可以分成 2 和几、2 和 3 合成几；翻出两张合成 5（或凑成 10）的数字卡 |
| ➕ ➖ 🧮 算一算 | 看图写算式、算得数、填方框里的数；加法、减法、0、连加连减、加减混合、十加几 |
| 🚂 开火车 | 口算：答对一题，火车加一节车厢，最后火车开走 |
| 📖 解决问题 | 乐乐讲一个小故事（“树上有 5 只小鸟，飞走了 2 只……”），选对算式，再算出得数 |
| 🧊 立体图形 | 认识长方体、正方体、圆柱、球：东西是什么形状、找出圆柱、数一数有几个球 |
| 🔟 小棒 · 🧮 计数器 | 十个一是一个十；看小棒或计数器说数，在计数器上拨数，十位和个位 |
| 🛤️ 数的顺序 | 数轴上的前面、后面、中间和空格里的数 |
| 🔟 凑十法 | 9 + 4：9 和几凑成十？4 分成 1 和几？10 + 3 = 13（看大数，分小数，凑成十，再加几）|

- 每个游戏的题目越来越难：前两题 3 个选项，后面 4 个而且更接近；题型会轮换。答错不扣分，错两次会提示正确答案。
- 乐乐会把每一句说明读出来，孩子不用认字也能玩。点左下角的乐乐可以再听一遍，也可以把乐乐拖到屏幕上任何地方。
- 乐乐的声音是预先录好的（`audio/zh/` 和 `audio/en/` 里约 5600 个 MP3），所以在任何浏览器里都能播放：微信里的浏览器、没有中文或英文语音的手机、打开了静音开关的 iPhone。
- 背景音乐是一段原创的木琴小曲（G 大调，约 37 秒），乐乐说话时会自动变小。
- 新题目出现的一瞬间不会算点击，所以手快的孩子不会因为上一题的点击被判错。
- 页面不能缩放：两根手指捏、连点两下都不会把页面放大或缩小（iPhone、iPad、安卓、触屏电脑都一样；电脑上的 Ctrl + 滚轮、触控板捏合和 Ctrl + 加号 / 减号也不会）。
- 每完成一个游戏得一颗 ⭐，学完一课得一张贴纸 🏆（火箭、飞碟、恐龙、小海豚……）。
- 玩到一半离开或刷新页面，回来会从同一道题接着玩（乐乐会说“欢迎回来”）；↺ 可以从头开始。
- **家长页面（👪）**：使用说明、语言（中文 / English）、语速、拼音显示/隐藏、音效、背景音乐、“显示乐乐说的话”（关掉声音也能玩）、“游戏长度：短”（每个游戏约 3 题）、把乐乐放回角落、声音测试、更新到最新版本、30 课的“家长 / 老师检查表”（会随着孩子完成游戏自动打勾，也可以手动勾选），以及“清除学习记录”（需要家长回答一道乘法题——孩子会做加法，所以不用加法题）。
- 学习进度只保存在这台设备的这个浏览器里，不会上传到任何地方；同时存在 localStorage、IndexedDB 和一个小 cookie 里，其中一个被清掉也不会丢。

## 小提示

- 请把音量调大。如果还是没有声音，请在手机自带的浏览器里打开（微信里点右上角“…”→“在浏览器打开”），并检查是否连接了蓝牙耳机或音箱。
- 每次玩 10–15 分钟就好。可以“添加到主屏幕”（分享 → 添加到主屏幕），以后像 App 一样打开。
- 首页、开始页面和家长页面底部会显示版本号（例如“版本 1 · 2026-10-06”）。网站有新版本时，首页会出现“🔄 新版本 … 来啦，点这里更新！”；也可以随时点首页右上角的 🔄。

## 发布到 GitHub Pages

这是一个静态网站：`index.html`、`favicon.ico`、`manifest.webmanifest`，加上 `css/`、`js/`、`audio/`、`fonts/`、`icons/` 文件夹，不需要编译。
`.github/workflows/deploy.yml` 会在每次推送到 `main` 分支时把这些文件发布到 GitHub Pages。
如果仓库还没有打开 Pages：**Settings** → **Pages** → **Build and deployment** → **Source** 选 **GitHub Actions**（只需要一次），然后在 **Actions** 页面重新运行 “Deploy to GitHub Pages”。

在本地运行：在这个文件夹里执行 `python3 -m http.server`，然后打开 http://localhost:8000 。
每次提交前请运行 `python3 tools/stamp.py`：它会把版本号加一，并把 CSS、JS 和语音文件的版本写进 `index.html`，这样浏览器不会把新页面和旧文件混在一起。

## 修改乐乐说的话

乐乐说的每一句话由 `allPhrases()`（`js/games4.js`）列出。修改课程或句子后重新录音：

```sh
pip install onnxruntime numpy scipy "misaki[zh]" lameenc praat-parselmouth kokoro-onnx av
NODE_PATH=$(npm root -g) node tools/export_phrases.js                  # 写出 tools/phrases.json（需要 playwright）
python3 tools/build_audio.py zh 模型文件夹                              # 只录新的句子，并更新 audio/zh/manifest.js
python3 tools/build_audio.py en kokoro-v1.0.onnx voices-v1.0.bin       # 英文
```

中文模型来自 [Kokoro-82M-v1.1-zh-ONNX](https://huggingface.co/onnx-community/Kokoro-82M-v1.1-zh-ONNX)（`onnx/model.onnx`、`tokenizer.json`、`voices/zf_078.bin`，和中文乐园是同一个声音）；
英文模型来自 [kokoro-onnx](https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0)（声音 `af_heart`，和 Phonics Fun 一样）。
中文句子的拼音由 `build_audio.py` 算出（pypinyin，多音字和“一”“不”的变调另外写在 `WORDS` 里），`--show` 可以只显示每一句怎么读。
单独的数字（一、二、三……）先让模型读出来，再用 Praat 把音高改成标准的声调，所以四个声调一定听得清清楚楚。
`--redo "句子"` 可以重录某几句，`--all` 全部重录。没有录音的句子会用浏览器自带的语音朗读。

检查：先运行 `python3 -m http.server 8765 &`，然后

- `NODE_PATH=$(npm root -g) node tools/smoke_test.js`：在手机、平板和横屏尺寸下、用中文和英文打开每一课的每一个游戏、贴纸页和家长页面（包括所有设置和“清除学习记录”），报告页面错误；
- `NODE_PATH=$(npm root -g) node tools/play_test.js`：把 30 课的每个游戏都从头玩到尾（写数字时真的沿着笔画写），并列出乐乐说了但没有录音的句子；加上 `WRONG=1` 会在答对之前先点错一次。

## 图标、音乐和字体

- 图标是 `icons/icon.svg` 里的一道一年级算术题“1 + 2 = ?”（绿色方块，黄色的答案框）；`NODE_PATH=$(npm root -g) node tools/make_icons.js`
  会画出其他尺寸（浏览器标签用的 16 像素版只画“1+2”）。改了图标以后，把 `index.html`、`manifest.webmanifest` 和 `js/core.js` 里图标的 `?v=` 加一。
- 背景音乐 `audio/music.mp3` 由 `python3 tools/make_music.py` 合成，没有任何版权限制。
- `fonts/kai.woff2` 由 `python3 tools/build_fonts.py gkai00mp.ttf` 生成（只保留页面上用楷体显示的字）。
